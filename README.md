# Autodesk Certified Professional (ACP) - AutoCAD Design and Drafting

WSQ courseware for **TGS-2023036004**, developed by Tertiary Infotech Academy Pte Ltd.

This v8.0 package is aligned to the current Autodesk AutoCAD Design and Drafting certification domains and the course learning outcomes. The slide deck is concept-led and visual; detailed procedures, verification checks and evidence requirements are provided in the Learner Guide and individual lab folders.

## Courseware

- `courseware/Autodesk-ACP-AutoCAD-Design-and-Drafting-v8.0.pptx` — editable trainer deck with native PowerPoint charts
- `courseware/Autodesk-ACP-AutoCAD-Design-and-Drafting-v8.0.pdf` — learner slide PDF
- `courseware/LG-Autodesk-ACP-AutoCAD-Design-and-Drafting.docx` and `.pdf` — detailed Learner Guide
- `courseware/LP-Autodesk-ACP-AutoCAD-Design-and-Drafting.docx` and `.pdf` — four-day Lesson Plan
- `LG-Autodesk-ACP-AutoCAD-Design-and-Drafting.md` — accessible Learner Guide source

## Hands-on labs

Each folder under `labs/` is self-contained and includes a detailed Markdown/PDF guide, evidence checklist, 1600x1000 JPEG reference image, and the relevant AutoCAD DWG working files.

1. Drawing Standards and Project Setup
2. Layers, Object Management and Revision Control
3. Annotation Standards and Stakeholder Story
4. Dimensions, Multileaders and Data Tables
5. Advanced Geometry and Precision Editing
6. Blocks, Attributes and Data Extraction
7. Layouts, Viewports and Page Setups
8. Publish, Plot and eTransmit
9. Xrefs, Underlays and Drawing Comparison
10. Integrated Sink Documentation Capstone
